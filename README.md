# Enterprise Flow CRM

Enterprise-level CRM system built with Spring Boot.

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT
- MySQL
- Redis
- Docker
- Swagger
- JUnit
- Mockito

## Branch Strategy

- main → Production
- dev → Development
- feature/* → Feature branches

- Authentication (JWT + Refresh Token)
- Role Based Access
- Lead Management
- Customer Management
- Task Assignment
- Follow-up System
- Email Notification
- Redis Cache
- Docker Deployment
